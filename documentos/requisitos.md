# Documentación del Sistema de Citas Médicas

## 1. Descripción
Sistema para gestionar citas médicas.

## 2. Objetivo
Facilitar el registro de pacientes y la programación de citas médicas.

## 3. Requisitos funcionales
- Registrar pacientes.
- Consultar médicos.
- Programar citas.
- Modificar citas.
- Cancelar citas.

## 4. Requisitos no funcionales
- Seguridad de la información.
- Facilidad de uso.
- Disponibilidad del sistema.
